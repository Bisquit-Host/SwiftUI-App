# Bisquit.Host

Bisquit.Host client for all Apple Platforms

### Supported Platforms
- iOS / iPadOS 26+
- visionOS 26+
- watchOS 26+
- macOS 26+ (deprecated)
- tvOS 26+ (deprecated)

### Features
- Sign in with Passkeys & OAuth services
- Collaborative text editor
- Push notifications
- Interactive widgets & Shortcuts with dynamic configuration
- Live Activity
